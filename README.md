# Golden Ink - Blog Website

## About Project
Golden Ink is a full-stack blog website where users can create, view, edit, and delete blog posts.

## Features
- Create new blogs
- View all blogs
- Edit existing blogs
- Delete blogs
- Responsive design
- Express.js backend API

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Project Structure

public/
- index.html
- add-blog.html
- style.css
- script.js

server.js

## How to Run

Install dependencies:

npm install

Start server:

node server.js

Open:

http://localhost:3000
